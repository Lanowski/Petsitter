# Petsitter Wrocław

Statyczny landing page Mariny i Andrzeja, przygotowany do publikacji przez
GitHub Pages i podłączenia własnej domeny.

## Najczęściej aktualizowane dane

- ceny usług: sekcja `#uslugi` w `index.html`;
- statystyki Petsy: sekcja `.stats` oraz karta `.rating-card`;
- numer WhatsApp: zmienna `whatsappNumber` na końcu `index.html`;
- zdjęcia: katalog `assets/`;
- link do profilu: wyszukaj w `index.html` frazę `petsy.pl/p/marina-andrzej`.

Przed publikacją trzeba potwierdzić ceny, teksty FAQ i zgodę na wykorzystanie
zdjęć oraz fragmentów opinii. Po akceptacji można dodać plik `CNAME` z własną
domeną i skonfigurować ją w ustawieniach GitHub Pages.
